PH-LENDING PRO — GUIDE D'INSTALLATION WINDOWS
==============================================

ETAPES D'INSTALLATION (3 actions seulement)
--------------------------------------------

  1. Extrayez ce fichier ZIP dans un dossier permanent
     (ex: Mes Documents, Bureau, disque D:, etc.)

     ⚠️  Ne l'extrayez PAS dans un dossier qui sera supprime !
         Le programme restera dans ce dossier apres installation.

  2. Ouvrez le dossier extrait et double-cliquez sur :

         ┌─────────────────────┐
         │     INSTALL.bat     │ ← Double-clic ici
         └─────────────────────┘

     Si Windows demande "Voulez-vous autoriser cette application ?",
     cliquez OUI (c'est normal pour les scripts .bat non signes).

  3. Attendez la fin de l'installation (5 a 10 minutes).
     Une fenetre noire affichera la progression.
     Ne la fermez PAS.

  → Un raccourci "PH-Lending Pro" apparaitra sur votre Bureau.
    Double-cliquez dessus pour lancer l'application !


CONNEXION INTERNET
------------------
  Une connexion Internet est requise lors de la 1ere installation
  (pour telecharger Python et les bibliotheques si absent).
  Apres installation, l'application fonctionne SANS Internet.


EN CAS DE PROBLEME
------------------
  • Windows bloque le fichier .bat ?
    → Clic droit sur INSTALL.bat → "Executer en tant qu'administrateur"

  • L'installation echoue avec une erreur de connexion ?
    → Verifiez votre connexion Internet et reessayez.

  • L'application ne s'ouvre plus apres avoir deplace le dossier ?
    → Relancez INSTALL.bat depuis son nouvel emplacement.


CONFIGURATION REQUISE
---------------------
  • Windows 10 ou Windows 11 (64 bits)
  • 500 Mo d'espace disque libre
  • Connexion Internet pour la 1ere installation uniquement
